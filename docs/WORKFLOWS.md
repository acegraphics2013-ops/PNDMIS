# Workflows and acceptance criteria

## Role boundaries
- Supervisor: department-wide operational visibility; restricted staff 201 fields according to formal authorization; final approval.
- Manager: assigned unit roster and deliverables, verify/return documents; no cross-unit access.
- Staff: own profile, submissions, learning history and assigned tasks only.
- Technical administrator: infrastructure maintenance; personnel data access must be separately approved.

## Deliverables
1. Create recurring requirement by staff, type, period, due date (scheduled job planned).
2. Staff submits private document reference; record timestamp.
3. Manager verifies or returns with reason.
4. Supervisor approves; record approver and timestamp.
5. Reports calculate on-time/late by **first valid submission time**, not by verification time.
6. Reminder cadence proposal: 7, 3, 1 days before due; 1 day after; manager escalation at 3 days late. Configurable after policy approval.

## Screen map
- Login / password recovery / MFA enrollment (MFA planned)
- Supervisor: command center, unit scorecards, pending reviews, compliance reports, staff 201, LDNI, staffing, tasks
- Manager: own-unit overview, roster, duty counts, verification queue, LDNI and deadlines
- Staff: my profile, my deliverables, upload/revision, my training, my tasks
- Administration: role grants, access requests, audit review, policy configuration

## KPI examples (must be approved)
- DTR compliance = valid submissions on/before deadline / eligible submissions ×100
- DAR compliance = same formula for DAR
- IPCR compliance = same formula per semester
- PRC renewal alert = licenses expiring within configured horizon
- Training participation = eligible staff with attendance / eligible staff ×100
- Shift coverage = on-duty staff / approved shift requirement ×100
- Overdue count = required records past deadline without valid submission

## Privacy and operations
No patient records or patient identifiers should be added to this staff-focused system. Sensitive personal data require minimal collection, explicit access control, secure storage, defined retention, and DPO review.
